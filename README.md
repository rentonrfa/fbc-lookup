# Fire Benefit Charge lookup

Public lookup of Renton Regional Fire Authority Fire Benefit Charges, embedded on https://rentonrfa.com/benefit-charge/.

lookup.json is generated from RRFA's FBC billing data. It contains parcel, account, address, property class, billed square feet, hazard class, sprinkler and alarm discounts, billed/exempt status, and this year's and last year's charge. It contains no owner names or contact details.

Questions: Fire Benefit Charge office, 425-988-4939.
